# ⚠️ WARNING

Script **Setuplaunch.bat** ini hanya berfungsi sebagai **launcher** untuk membuka Windows 11 Setup (`setup.exe`).

## ❌ Bukan Installer Otomatis
- Tidak melakukan install ulang otomatis.
- Tidak memformat drive.
- Tidak menghapus data pengguna.

## ✅ Fungsi Utama
- Membuka `setup.exe` dari ISO Windows 11 yang sudah di-mount.
- Memberikan pesan informasi jika `setup.exe` tidak ditemukan.

---

### 📜 Catatan Penting
Gunakan ISO Windows 11 resmi dari Microsoft.  
Jangan jalankan script ini untuk tujuan selain membuka installer.
