# Win11 Setup Launcher

Script sederhana untuk membuka **Windows 11 Setup** langsung dari file ISO.  
Tujuan: mempermudah pengguna agar tidak perlu klik manual `setup.exe`.

## 📦 Persyaratan
- Windows 10/11
- File ISO Windows 11 resmi dari Microsoft
- PowerShell (sudah ada default di Windows)

## 🚀 Cara Pakai
1. Download ISO Windows 11 dari situs resmi Microsoft.
2. Simpan ISO di folder, misalnya: `C:\Users\Public\Downloads\Win11.iso`.
3. Clone repo ini:
   ```bash
   git clone https://github.com/username/Win11-Setup-Launcher.git
